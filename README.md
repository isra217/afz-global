# AFZ Global – Corporate Website (Pakistan)

A modern, responsive corporate website developed for **AFZ Global Pakistan**, showcasing professional business, technology, and digital solutions through a clean and user-friendly interface.

 **GitHub Repository:** https://github.com/isra217/afz-global

---

##  About the Project

AFZ Global is a corporate business website designed to establish a strong online presence for the company's Pakistan-based operations.

The platform presents the company's services, industry expertise, and business solutions in a professional and accessible way.

The website is designed to help potential clients explore services, understand available solutions, and connect with the company.

---

##  Key Features

- **Modern UI Design:** Professional and visually appealing corporate interface.
- **Responsive Layout:** Optimized for desktop, tablet, and mobile devices.

##  Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/isra217/afz-global.git
```

### 2. Navigate to the Project Folder

```bash
cd afz-global
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Run the Development Server

```bash
npm run dev
```

### 5. Open in Browser

Visit:

```text
http://localhost:3000
```
